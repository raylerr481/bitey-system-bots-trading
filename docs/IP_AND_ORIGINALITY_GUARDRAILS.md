# Bitey SBT — IP and Originality Guardrails

## Objective

Protect the Bitey SBT implementation from accidental reproduction of a competitor's protected expression while allowing normal product research and implementation of non-exclusive market capabilities.

## Allowed

- Studying public product descriptions.
- Identifying user problems and general workflows.
- Implementing common capabilities independently.
- Designing new algorithms, contracts and data models.
- Creating original UX and visual identity.
- Comparing Bitey SBT capabilities with market alternatives at a high level.

## Not allowed

- Copying source code.
- Reusing competitor assets, logos or artwork.
- Copying text or copywriting.
- Recreating screenshots pixel-for-pixel.
- Reproducing distinctive layouts or interaction design merely to imitate a competitor.
- Importing proprietary prompts, algorithms or implementation details.
- Using competitor branding or confusingly similar product names.

## Design process

For every feature inspired by an observed market capability:

1. Write the user problem without naming the competitor.
2. Define the desired outcome.
3. Design the Bitey workflow from first principles.
4. Create Bitey-specific terminology.
5. Implement original components and contracts.
6. Test the feature against functional requirements, not visual similarity.
7. Record the decision in product documentation when the feature is strategically important.

## Review rule

A feature is not rejected merely because another product also has a similar high-level capability. It must be redesigned when the implementation starts reproducing protected expression or a distinctive presentation rather than solving the underlying problem independently.

## Evidence and provenance

AI-generated strategy proposals, external model outputs and third-party market information must be treated as inputs. The final Bitey SBT strategy specification, evaluation record and executable implementation must remain under Bitey's own contracts and validation process.

## Legal note

These engineering guardrails are risk-reduction practices, not legal advice. Trademark, copyright, patent, trade-secret and unfair-competition questions should be reviewed by qualified counsel before commercial launch where appropriate.
